# 扫雷集合 — MINESWEEPER ARCHIVE

同一个雷场，不同的空间。这里收录几个**保留经典规则、换掉棋盘几何**的扫雷变体，每个都独立、零构建、零依赖、离线可玩。

> **[▶ 打开集合](https://hex1um.github.io/mine4d/)**

| 变体 | 玩法 | 版本 |
| --- | --- | --- |
| **[MINE·4D](4d/)** — 四维排雷 | 雷场是 `x × y × z × w` 的四维晶格；三种视图（平面切片 / 立体晶格 / 四维并排）；两套邻域（面邻 8 / 全域 80）；4D 邻域扫描仪 | v1.1.1 |
| **[FRACTAL·MINE](fractal/)** — 分形排雷 | 无限平面，雷的密度由 Julia 集的逃逸时间决定，雷沿分形丝状边界聚集；可无限平移缩放，逐块清空「扇区」 | v0.1.0 |

## 共同规则

- 数字 = 该格邻域中的雷数（无雷为空格，空格自动连片翻开）
- 首击必定安全
- 左键排雷 / 右键插旗 / 已开数字上左键快开
- 计时、剩余雷数、进度都直接读局面真值，不做"提示作弊"

## 结构

```text
index.html          # 集合入口
4d/                 # 变体 01：四维排雷（自带 README 与 js/）
fractal/            # 变体 02：分形排雷
bump-version.mjs    # 统一所有页面的 ?v= 版本串（Node，零依赖，不参与运行）
tools/              # 无头 Chromium 冒烟测试与线上验收（开发用）
```

每个变体都是纯静态页面，直接双击各自的 `index.html` 也能玩。

## 本地运行

```bash
python -m http.server 8898
# 打开 http://127.0.0.1:8898/
```
