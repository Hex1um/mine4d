# FRACTAL·MINE — 分形排雷

经典扫雷规则，但雷场是**分形**的：雷的密度由 **Julia 集**的逃逸时间决定，所以雷会沿着分形的丝状枝杈聚集。棋盘无限大，可以一直平移、缩放。

> 在线试玩：https://hex1um.github.io/mine4d/fractal/ （或直接打开本目录的 `index.html`）

## 规则（与经典一致）

- 数字 = 周围 8 格的雷数；0 自动连片翻开（单次最多铺开 110 格）
- 首击必定安全：点击格与它的 8 邻一起排空
- 左键排雷 · 右键 / 长按插旗 · 已开数字上左键快开

## 不同的地方

每个坐标先算一次 Julia 集（`z ← z² + c`，**c = i**，即「树状」Julia）的逃逸步数 ε，再用 ε 落在枝杈附近的程度决定该格是雷的概率（ε ≈ 8 时最密，约 47%）。取 c = i 的原因是这棵枝杈**没有内部**——地图上处处都是边界，不会出现一大片「集合内部」的空区让开局无事可做。

雷与否由「坐标 + 种子」的哈希与密度阈值唯一确定，所以**平移、缩放、关掉再打开，雷场都不会变**。

## 目标

雷场无限，所以目标不是清空全图，而是清空虚线框住的 **9 × 9 扇区**：把扇区内所有非雷格翻开即算清空，累计计数并自动指向下一个未清扇区（`N` 键跳过去）。踩雷则本局结束，`R` 换种子重开。

## 操作

| 操作 | 说明 |
| --- | --- |
| 拖动 / 箭头键 | 平移（箭头每次 3 格） |
| 滚轮 / 双指 / `+` `-` | 以光标为锚缩放（9px ~ 64px 每格） |
| 左键 | 排雷；已开数字上 = 快开 |
| 右键 / 长按 | 插旗 |
| `N` 下一扇区 · `R` 重新播种 · `H` 手册 | |
| `F` 进出游戏屏 · `Esc` 返回 · 「‹ 合集」回入口 | |
| 「密度场」开关 | 把理论概率用青色底噪画出来（只给概率，不给具体雷位） |

## 文件

```text
index.html    # 终端骨架：顶栏 / 画布 / 控制 / 手册
style.css     # 深空终端视觉
js/field.js   # 无限雷场：哈希、Julia 逃逸时间、密度场、扇区统计
js/render.js  # 平移缩放绘制、密度热力、扇区框
js/main.js    # 输入、计时、存档、HUD
```

## 手机端

默认直接进入**游戏屏**：画布独占整屏，状态以悬浮 HUD 呈现（顶部「‹ 返回 · 分形 · 深度 · 世界格 · 雷 · 时间 · 进度」，右侧 ＋/− 下潜上浮，右下 下一扇区/密度场/手册）。**返回键**退出到概览态（顶栏 + 分形选择 + 棋盘预览），顶栏的「进入游戏屏」再回去。

零构建、零依赖，纯 canvas 2D；字体复用 `../4d/fonts`。
