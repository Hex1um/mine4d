# MINE·4D — 四维排雷终端

把经典扫雷搬到**四个正交维度**：雷场是 `x × y × z × w` 的四维晶格，你每次只看到 `(x, y)` 这一片平面，用「层 Z」和「相位 W」在四维里移动。界面做成深空排雷终端的样子：CRT 扫描线、青蓝荧光、四维邻域扫描仪。

> 打开 `index.html` 就能玩，零构建、零依赖、离线可用。

## 玩法

| 操作 | 说明 |
| --- | --- |
| **左键** | 排雷（在已开的数字上左键 = 快开：周围旗数等于数字时揭开其余） |
| **右键 / 长按** | 插旗 |
| **方向键** | 移动光标 · **空格** 操作光标格 · **F** 插旗 · **C** 快开 |
| **W / S** 或底部滑杆 | 切相位 W · **A / D** 或 `Z0–Zn` 切层 Z |
| **T** 自动推理 · **G** 提示 · **R** 重新布雷 · **H** 手册 | |

- **首击必定安全**：第一次点击的格子连同它的整个邻域都会被排空。
- **四种难度**：侦察 4×4×4×4 → 熵增 10×10×6×5（最大 3000 格、250 枚雷）。
- **纪录**按难度存在浏览器本地。

## 两种邻域（4D 扫雷的关键设置）

| 模式 | 邻域 | 数字范围 | 手感 |
| --- | --- | --- | --- |
| **面邻 8**（默认） | 四个维度上「贴着」的 8 个格子：±x、±y、±z、±w | 0–8 | 与经典扫雷完全同构，纯逻辑可推完，难点在于还要在 Z / W 上走位 |
| **全域 80** | 四维切比雪夫邻域（同层 8 邻 + 上下层各 9 + 相邻相位各 27） | 0–80 | 硬核。数字很大，必须靠扫描仪拆解邻域 |

## 为四维准备的三个工具

- **相位剖面**：当前层 Z 在 W−1 / W / W+1 上的三张切片缩略图——上下相位的局面一眼可见。
- **4D 邻域扫描仪**：把选中格的邻域按「3 个相位 × 3 个层」拆成 9 个 3×3 小块，每块标出未知格数与旗数。面邻模式下不属于邻域的格子会被压暗。
- **自动推理 / 提示**：推理器只做两类铁定成立的推导（邻域已标满 → 剩余未知格安全；未知格数等于剩余雷数 → 全是雷），不会瞎猜；若当前局面无确定解，「提示」会退化为给出**局部风险最低的猜测**并标明估计踩雷率上限。

## 技术说明

- 纯原生 HTML / CSS / JavaScript，**零构建、零依赖**；经典 `<script>` 加载，双击即可运行。
- 渲染全部走 canvas 2D：主雷场、三张相位缩略图、邻域扫描仪各一块画布，数字用本地 Space Mono。
- 逻辑在 `js/core.js`：四维索引、邻域偏移表、洪水填充（单次最多铺开 120 格，避免一键掀掉半张图）、确定性推理器与概率估算。

```text
index.html      # 终端骨架：顶栏 / 雷场 / 侧栏 / 相位与层控制
style.css       # 深空终端视觉：CRT、切角面板、荧光色板
js/core.js      # 四维雷场逻辑 + 推理器 + 概率估算
js/render.js    # 雷场 / 相位缩略图 / 邻域扫描仪（canvas）
js/ui.js        # HUD、日志、开机自检、手册
js/main.js      # 状态、输入（鼠标 / 键盘 / 触屏）、主循环、存档
bump-version.mjs# 版本串同步（Node，零依赖，不参与运行）
tools/smoke.mjs # 无头 Chromium + CDP 冒烟测试（开发用）
fonts/          # 本地 Space Mono / Outfit（OFL）
```

## 本地运行

```bash
python -m http.server 8898
# 打开 http://127.0.0.1:8898/
```

冒烟测试（需要本机有 Playwright 的 Chromium）：

```bash
node tools/smoke.mjs http://127.0.0.1:8898/ ./tools/out
```
